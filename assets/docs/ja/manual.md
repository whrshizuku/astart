Start（启序）はローカルで動作するメモアプリです。やることを小さなステップに分解し、一度に一つのことに集中できるよう手伝います。神経多様性のある方に向けて作られました：励ましの表現、低抵抗、責めない。データはすべてデバイス内に保存。更新確認以外のオンライン音声認識、AIアシスタント、クラウドバックアップはすべてデフォルトでオフ。有効にして、なおかつあなたが明示的に使う時だけ通信します。

> オリジナル性とAIの補助について：このアプリは個人の開発者によって設計され、AIツールはコーディングの補助としてのみ使われました。プロダクトのデザイン、交互ロジック、ワークフローはすべて開発者のオリジナルです。AIはデザイン決定には関与していません。

> 拡張機能はプレビュー状態にあり、API スタブのみ残しています。コア交互は一時的に撤去、後続のアップデートをお待ちください。

# ホーム

上から：フォーカス、大時計、予定、いつでも。プレーンテキストのリスト、一目で全て見渡せます。大時計の横には励ましの文が——一日の事が全部終わると「今日の事は全部終わりました、すごい」と出ます。

予定エリアといつでもエリアは**完全に同じ交互モデル**です：
- **左側（頭部）長押し 120ms = ドラッグ**：**下部の赤いゴミ箱**（5秒以内なら取り消し可）に捨てるか、モジュール間をドラッグ（いつでもを予定エリアにドラッグ=日時を選んで予定化、ホームの行を上にドラッグ=フォーカス設定）。
- **右側（尾部）長押し = 多选開始**。多选時は頭部がグレーのドラッグハンドルに、尾部が唯一の選択円（カラー=選択済み）になります。上部バーには**全選**（グレーアウトライン、セカンダリ）と**完了**（赤ソリッド、プライマリ）の二つだけ。削除は統一して下部の赤ゴミ箱です。
- **行間ドラッグで並べ替え**：長押しでハイライトされた隙間が現れ（先頭の隙間もあり）。上にドラッグ=先頭へ、下にドラッグ=後ろへ。再起動後も並び順を記憶します。

# フォーカス

画面最上部の大きな見出しエリアです。フォーカス未設定時は「一つのことだけに集中」と表示されます。「はじめる」をタップすると、今日の未完了から一つ選ぶか、新しく一つ書けます。また、任意のタスクを**頭部長押しで上までドラッグ**してフォーカスにすることもできます。集中タイマーは下部バーの「集中」タブにあります。

選択するとタイトルが大きく表示され、メインボタン「これだけやる」でステップ画面に進み、タスクを細かく分解できます。ほかにも完了、別のものにする、編集があります。やり切ると「メイン目標、達成です」と表示され、「次へ」で次に進めます。

# 予定

時間が決まったタスクは**手動ランク（ドラッグ並べ替えで書き込み）を優先**、`dueTime` で補完して並び、右側に時刻が表示されます。期限を過ぎた未完了項目は日付が出るだけで、赤くなったり責めたりはしません。スマホのカレンダーの当日予定は小さな四角い点として横に並び、重複は自動で除かれます。未来の予定はその日になると自然に現れます。完了した予定は一覧から自動で消え、記録は統計と検索に残ります。

- **予定エリア内ドラッグ並べ替え**：ホーム両エリアと同じ統一交互。
- **行の右端の小さな丸ボタン**：「やらない」（取り消し可）または「別の日にする」（明日 / 明後日 / 3日後 / 日付を選ぶ）。
- **「予定」という小見出し長押し**で多选開始、上部バーは全選+完了、赤ゴミ箱で削除。
- **新規作成**（右上の「+」）：改行で複数件まとめて書き、共通の日時を一つ選ぶ。
- **時間になったら出るフローティングリマインダー**は既定でオン。「カレンダーに書き込む」「システムアラーム」は任意——編集画面で対応するボタンを押すか、一括作成時にチップを点灯させたときだけ実行されます。

# いつでも

時間を決めていないことはすべてここに置かれます。右上の「+」で複数件をまとめて書けば、改行と句読点で自動的に複数件に分割されます。

- **いつでもエリア内ドラッグ並べ替え**：ホーム両エリアと同じ統一交互。
- **任意の項目を予定エリアにドラッグ**：日時を選ぶエディタが開き、**確定後**に元の項目が削除されます。途中でキャンセルすれば元の項目はそのままです。
- **行の尾部をタップ**で編集画面を開き、その場で日時を設定できます。

# マインドマップ

- **ページ上部バー**：一括インポート（予定/いつでも/ステップを複数選んで現在のマップのルートにコピー）+ レイアウト回復。
- **下部ツールバー**：ルート選択時=子ノード追加（accent メイン）+ 一括整理；非ルート選択時=子ノード追加 + 編集 + 一括整理；未選択時は「一括整理」入口のみ。**削除は一様に底部の赤いゴミ箱**（ノード長押し 120ms でドラッグ開始）。
- **ノードの交互（完全に分離、競合ゼロ）**：
  - **タップ**=選択；**ダブルタップ**=テキスト編集。
  - **押してドラッグ（Listener raw pointer）**=サブツリーごと自由配置；**ピンチでズーム**；レイアウト回復ボタンで自動配置に戻す。
  - **長押し 120ms → 底部赤ゴミ箱にドラッグ**：子枝ごと削除、5秒以内なら取り消し可。ルートノードはロック（削除不可、ドラッグ不可）。ホーム/検索/ステップページと完全一致。
- **ノードインポート**：予定/いつでも/小ステップを複数選んでマップにコピー（上部バー=ルート直下、ツールバー=選択ノードの子枝）。元の項目はそのままです。

# フィードバック

- **ドラッグ開始時**：`mediumImpact` 振動 + 120ms 長押しトリガ + 浮影 `scale 1.02` + 柔らかい影 + 丸角。
- **ホバー時**（並べ替え隙間 / ゴミ箱 / 予定ドロップゾーン）：エッジトリガ振動（最初の1回だけ、ホバー中は連続しない）+ ハイライト影付き隙間。
- **長押しで多选開始 / タップで切り替え**：`selectionClick` 振動。

# 服薬

下部バーの1番目にあるカプセルアイコン。日付をめくって毎日飲む薬を時刻順に確認できます。カードには薬の名前・用量・服薬時刻・分類を表示。右下の「+」で新しいプランを作成：薬の名前を入力し、服薬時刻を一つずつ追加（24時間制で好きな時刻をいくつでも）。用量・分類・開始/終了日も任意で設定できます。保存すると設定時刻に合わせて毎日自動でリマインダーが組まれ、システムアラームにも紐づけられます（30日分をローリング）。プランを削除すると自動で取り消されます。右上のカレンダーアイコンで月表示に切替：日付の下の状態ドットで一目で分かります——緑=すべて服用、黄=一部服用、トマトレッド=服用漏れ（グレー=未来）。日付をタップするとその日に戻ります。服薬データは独立して保存され、ホームのリストや検索結果には表示されません。

# 検索

ホーム上部バーの設定の左にある虫めがね。すべての項目（予定・いつでも・ステップ）をタイトルやメモで検索。ホーム両エリアと同じ交互：**頭部長押し→赤ゴミ箱削除**（5秒取り消し）、**尾部長押し→多选**、上部バー全選+完了。

# メモ

下部バー中央の赤い丸ボタンです。短押しは文字速记：まず書くだけで分類は不要。「放り込む」をタップすると、改行と句読点で自動的に複数件に分割され、整理画面に進みます。

# 整理

下部の入力欄でもすぐメモできます。改行で複数書くと、保存時に行と句読点で自動的に受信箱の複数項目に分かれます。ルールは「メモ」と同じです。振り分け：1件ずつ予定（日時を設定できる）またはいつでもに分けると、ホームの対応するエリアに自動で流れていきます。
マインドマップでは、ノードをタップして選択すると、子ノード・同階層ノードの追加、編集、削除ができます。ドラッグでサブツリーごと移動、ピンチで拡大縮小できます。
右上の「+」で受信箱に1件追加。「一括整理」では全選に対応した一括操作ができます。

# リマインダーとカレンダー

予定に日時を設定すると、時間になったら出るフローティングリマインダーが既定でオンになります。「カレンダーに書き込む」「システムアラーム」は任意で、編集画面で対応するボタンを押す（または一括作成時にチップを点灯させる）と実行されます。服薬プランは保存すると自動で毎日のリマインダーが組まれ、システムアラームにも紐づけられます。プランを削除すると自動で取り消されます。

# 集中と統計

集中：円環とカウントダウンだけ、干渉なし。事前に長さを選ぶ：プリセット 2 / 25 / 45 分、またはカスタム 1–240 分。分ごとのチック、完了時の音/振動/無音、音量は設定で調整。
統計：日付ベースで左右スワイプ。1ページに4つの大数字：当日の集中時間、集中回数、完了件数、新規登録件数。下部は24時間の集中分布棒グラフ。

# データと更新

検索でどの項目も見つけて削除できます（取り消し可）。設定で JSON エクスポート、インポート前に自動スナップショット、取り消し可。アンインストールするとデータは全て消えるので、先にエクスポートしてください。アップデートは自動で通知されます。

# 拡張機能（プレビュー）

設定 → 拡張には3つの任意機能があります：オンライン音声認識（精度向上のためシステムオンラインエンジンを許可）、AI アシスタント（フリーデフォルトまたは任意の OpenAI 互換エンドポイント、「AI 整理」をタップしたときだけ送信）、クラウドバックアップ（WebDAV、自分のサーバーまたは坚果雲、手動トリガーのみ）。使わなければ通信しません。
