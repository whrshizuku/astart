Start（中国語名：启序）は、ローカルで動くメモ＆タスクアプリです。やることを小さなステップに分解し、「一度に一つだけ」やり切ることを助けます。ADHDの傾向がある方に向けて、励ます言葉、低い心理的負荷、責めないデザインにしています。データはすべて初期設定で端末内にのみ保存されます。更新確認を除き、オンライン音声認識・AIアシスタント・クラウドバックアップはすべて任意機能で既定オフ。あなたがオンにして能動的に使ったときだけ通信します。

# 使い方のコツ：放り込む → 整理する → やる
放り込む：思いついたらまず全部書く。分類は後回しでOK。
整理する：空き時間に受信箱を「予定」か「いつでも」に振り分ける。
やる：一日のフォーカスは一つだけ。大きいことは小さなステップに分解する。

# ホーム
上から順に、フォーカス、大きな時計、予定、いつでも。テキストだけの一覧で全体を一目で把握できます。時計の横にはいつも励ましの一言が添えられ、その日の項目を全部やり切ると「今日のことは全部やり切りました、すごい」と表示されます。

# フォーカス
画面最上部の大きな見出しエリアです。フォーカス未設定時は「一つのことだけに集中」と表示されます。「はじめる」をタップすると、今日の未完了から一つ選ぶか、新しく一つ書けます。任意のタスクを長押しで上部までドラッグしてフォーカスにすることもできます。集中タイマーは下部バーの「集中」タブにあります。
選択するとタイトルが大きく表示され、メインボタン「これだけやる」でステップ画面に進み、タスクを細かく分解できます。ほかにも完了、別のものにする、編集があります。やり切ると「メイン目標、達成です」と表示され、「次へ」で次に進めます。
ステップ：入力欄に1行書くごとに保存され、改行で複数書けます。保存時に行ごとのステップに分かれます。タイトルは予定の名前だけで、分割の対象にはなりません。すべて完了するとタスクが自動でチェック済みになります。

# 予定
時間が決まったタスクは時刻順のテキスト一覧になり、右側に時刻が表示されます。期限を過ぎた未完了項目は日付が出るだけで、赤くなったり責めたりはしません。スマホのカレンダーの当日予定は小さな四角い点として横に並び、重複は自動で除かれます。未来の予定はその日になると自然に現れます。
右上の「+」で予定を作成します。改行で複数件まとめて書き、共通の日時を一つ選んでまとめて登録できます。保存すると自動でスマホのカレンダーに書き込まれ、システムアラームも静かにセットされるので、時間になったら通知が届きます。手動設定は不要です。

# いつでも
時間を決めていないことはすべてここに置かれます。右上の「+」で複数件をまとめて書けば、改行と句読点で自動的に複数件に分割されます。
ハンドルをドラッグして並べ替え。行をタップして編集画面を開き、その場で日時を設定して予定に変えることもできます。

# どこからでもドラッグ：ゴミ箱へ
どの項目（予定、いつでも、ステップ、検索結果）でも長押しでドラッグすると、下部にゴミ箱付きの赤いエリアがせり上がります。そこへ捨てると削除され、6秒以内なら元に戻せます。複数選択中は、選択項目の一つをドラッグするとまとめて削除されます。
ショートカットもあります。ホームで行を一番上までドラッグ＝フォーカスに設定。「いつでも」を予定エリアへドラッグ＝日時を選んで予定に変換。間違えてもどちらも元に戻せます。

# 検索
下部バーの虫めがねは、全タスクの管理台です。すべての項目（予定・いつでも・ステップ）をタイトルやメモの文字列で探せます。下のカテゴリボタンで一発絞り込み、タップで編集へ、削除は長押しドラッグで下部のゴミ箱へ。
右上から一括選択モードに入れます。選んだ項目の一つをドラッグすると、まとめて下部のゴミ箱へ捨てられ、誤っても元に戻せます。

# メモ
下部バー中央の赤い丸ボタンです。タップするとテキストメモになります。まず書くだけで分類は不要。「放り込む」をタップすると、改行と句読点（。！？；…）で自動的に複数件に分割され、整理画面に進みます。
長押しすると音声メモになります。初期設定ではスマホ内蔵のオフライン音声エンジンを使い、通信しません。話し終わると自動で聞き続け、「話し終わった」をタップするとテキスト画面で内容を確認してから放り込めます。AIアシスタントをオンにすると「AIで整理」ボタンが増え、話した内容が予定・いつでも・ひらめきに自動で振り分けられます。まとめて元に戻すこともできます。

# 整理
下部の入力欄でもすぐメモできます。改行で複数書くと、保存時に行と句読点で自動的に受信箱の複数項目に分かれます。ルールは「メモ」と同じです。
振り分け：1件ずつ予定（日時を設定できる）またはいつでもに分けると、ホームの対応するエリアに自動で流れていきます。
マインドマップでは、ノードをタップして選択すると、子ノード・同階層ノードの追加、編集、削除ができます。ドラッグでサブツリーごと移動、ピンチで拡大縮小できます。
取り込みアイコンから、予定・いつでも・ステップをマップにコピーして分解できます。ノードを長押しすると、テキスト編集、子ノード追加、枝の切り取りに直接進めます。
右上の「+」で受信箱に1件追加。「一括整理」では全選択に対応した一括操作ができます。

# リマインダーとカレンダー
予定を作成して保存すると、自動でスマホのカレンダーに書き込まれ、システムアラームも静かにセットされるので、手動操作なしで時間に通知が届きます。編集画面からリマインダーのオン/オフやカレンダーへの書き込み状態を確認することもできます。
リマインダーはすべて端末内で処理され、再起動後も自動で再設定されます。各スイッチは設定内にあります。

# 集中と統計
集中：リングとカウントダウンの数字だけの、邪魔のない表示です。時間は開始前に選びます。プリセットは2・25・45分、または1〜240分でカスタム可能。実行中の時間は大きく表示されます。1分ごとの時報音、完了時のお知らせ方法と音量は設定で調整できます。
統計：日付ごとに、左右のスワイプで集中時間（分）・集中回数・完了件数・新規項目数・24時間の分布を見比べられます。大きなテキスト数字で、進捗を客観的に記録します。

# データと更新
検索からどの項目でも見つけて削除でき、誤っても元に戻せます。設定からJSONバックアップを書き出しできます。取り込み前には自動でスナップショットが取られ、元に戻せます。アプリをアンインストールすると全データが消えるので、先に書き出してください。新バージョンは自動で通知されます。

# 拡張機能（すべて既定オフ）
設定 → 拡張機能には、任意でオンにできる3つの機能があります。オンライン音声認識（システムがオンラインエンジンを使えるようにし、認識精度が上がります）、AIアシスタント（無料モデルがプリセット済み。任意のOpenAI互換APIも設定可能で、「AIで整理」を押したときの文章だけが送信されます）、クラウドバックアップ（WebDAV。あなたのサーバーまたはナッツクラウドへ手動でバックアップします）。オンにしなければ通信せず、設定はすべて端末内にのみ保存されます。
