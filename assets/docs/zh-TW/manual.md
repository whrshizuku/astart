啟序（英文名 Start）是一款本機記事工具：把待辦拆成小步驟，幫你一次只做好一件事。為神經多樣性人士設計：措辭鼓勵、低阻力、不責備。所有資料預設僅存於裝置本機；除檢查更新外，線上語音、AI 助手、雲端備份均為預設關閉的選用功能，開啟後才會在你主動使用時連網。

> 原創與 AI 輔助聲明：本應用由個人開發者獨立設計，開發過程中藉助人工智慧工具輔助編碼；產品的設計方案、互動邏輯與工作流程均為開發者原創，AI 僅用於功能實現，不參與原創設計，開發者僅對產品的「現狀」負責。本說明書由簡體中文原文經 AI 翻譯生成，僅供參考。

# 使用心法：倒 → 理 → 做
倒：想到什麼先全寫下來，不必分類。
理：抽空把暫存分揀到行程或隨手做。
做：一天只盯一件焦點，事情大就拆成小步驟。

# 首頁
由上而下：焦點、大時鐘、行程、隨手做。純文字清單，一眼看完。大時鐘旁常駐一句鼓勵——一天的事都做完時是「今天的事都做完了，了不起」。

# 焦點
頁面最上方的大標語區。沒有焦點時顯示「只專注一件事」，點「開始吧」：有事就從今日未完成裡挑一件，沒有就現寫一件；也可以把任意任務長按拖到頂部設為焦點。進入專注一律走底欄的「專注」頁。
選定後以大字顯示標題，主按鈕「只做它」自動進入小步驟頁把事拆小；另有完成、換一件、編輯。完成後顯示「主線完成，漂亮」，點「下一件」繼續。
小步驟：輸入列寫一步存一步，按 Enter 換行可多寫幾步，儲存時依行拆分。標題僅為事件名，不參與拆分。全部完成後任務自動勾掉。

# 行程
定時的任務依時刻排成純文字清單，右側標註時刻；過期未完成的僅標註日期，不變紅、不責備；手機日曆當天事件以小方點並排顯示，自動去重。未來的行程到了那天自然出現。完成的行程會自動從清單消失，記錄留在統計與搜尋裡。
右上角加號新建行程：可換行一次寫多件，選一個共同的日期時間一次排進。到點懸浮提醒預設開啟；「寫入日曆」「系統鬧鐘」是選用項——編輯器裡點對應按鈕，或批次新建時點亮膠囊，才會執行。
點行尾小圓鈕可「不做了」（可復原）或「改日再做」（推到明天 / 後天 / 三天後或自選日期）；長按「行程」小標題進入選擇態，可全選後點頂欄垃圾桶批次刪除，誤刪可復原。

# 隨手做
沒定時間的事都待在這。右上角加號可一次寫多件，換行或句末標點自動拆成多則。
拖曳把手排序；點列打開編輯器，可就地設時間變成行程。

# 全域拖曳：拖到垃圾桶
任意一則（行程、隨手做、小步驟、搜尋結果）長按拖起，底部會升起一條紅色區域，中間一個垃圾桶——丟進去即刪，5 秒內可復原；多選時拖起任一已選項目，整組一起刪。
另有快捷拖法：首頁把列拖到頂部＝設為焦點；隨手做拖進行程區＝選個時間轉成行程。拖錯都可復原。

# 服藥
底欄第一格的膠囊圖示。按日期翻頁查看每天該吃的藥，依時刻先後排序；藥品卡顯示名稱、劑量（如 1 錠 / 0.25g）、服藥時刻與分類。右下角加號新建計畫：寫藥名、逐一新增服藥時刻（24 小時制，任意幾個都行），還可填劑量、分類與起訖日期；儲存後依所設時刻逐日自動設好到點提醒並綁定系統鬧鐘（未來 30 天滾動），刪除計畫自動撤銷。右上角日曆圖示切到月曆檢視，哪天該吃、哪天已服一眼看清，點日期跳回當天。點藥品卡左側圓圈記錄當次已服，頂部分類膠囊一鍵篩選。服藥資料獨立儲存，不進首頁清單與搜尋結果。

# 搜尋
首頁頂欄設定左側的放大鏡，就是全部任務的管理台：搜尋全部項目（行程、隨手做、小步驟），標題或備註包含即命中。下方分類鈕一鍵篩選，點一則直達編輯，刪除就長按拖到底部垃圾桶。
右上角進入批次模式：點選後拖起任一已選項目，整組拖進底部垃圾桶，誤刪可復原。

# 動手吧
底欄中央紅色圓鈕。短按是文字速記：先寫下來，不必分類；點「倒進來」後依行與句末標點（。！？；…）自動拆成多件，進入理一理。

# 理一理
底部輸入列可直接速記：換行多寫幾條，儲存時依行與句末標點自動拆成多則暫存，與「動手吧」同一規則。
分類：逐則分到行程（可設日期時間）或隨手做，分類後自動流入首頁對應區域。
心智導圖點按選中節點後可加子枝、加同級、編輯、刪除；按住拖曳可連同子樹移動，雙指縮放。
點匯入圖示可把行程、隨手做、小步驟複製進導圖拆解；長按節點直達編輯文字、加子節點、剪掉這枝。
右上角加號新建單則暫存；點「批次整理」進入批次操作，支援全選。

# 提醒與日曆
行程設好時間後，到點懸浮提醒預設開啟；「寫入日曆」「系統鬧鐘」為選用項，在編輯器裡點對應按鈕（或批次新建時點亮膠囊）才會執行。服藥計畫儲存後自動逐日設好提醒並綁定系統鬧鐘，刪除計畫自動撤銷。
提醒全部在本機完成，重啟或清理後台後自動重排；相關開關在設定內。

# 專注與統計
專注：僅顯示圓環與倒數數字，無干擾。時長在進入專注前選擇：預設 2 / 25 / 45 分鐘，或自訂 1–240 分鐘，當前時長會以大字顯示。每分鐘滴答一聲、做完提示方式與音量在設定中調整。
統計：以日期為維度，左右滑動切換查看不同日期的專注分鐘數、專注次數、完成件數、新增項目和 24 小時整點分布。純文字大數字，客觀記錄進展。

# 資料與更新
搜尋裡可以找到並刪除任何項目，誤刪可復原。設定中可匯出 JSON 備份，匯入前自動快照、可復原。解除安裝應用即刪除全部資料，請先匯出。有新版本時會自動提醒。

# 擴充功能（預設全關）
設定 → 擴充裡有三個自願開啟的能力：線上語音辨識（允許系統走線上引擎，辨識更準）、AI 助手（預設免費模型或自填任意 OpenAI 相容介面，僅在點「AI 整理」時傳送當時那段話）、雲端備份（WebDAV，備份到你自己的伺服器或堅果雲，僅手動觸發）。不開不用就不連網，設定只存在本機。
