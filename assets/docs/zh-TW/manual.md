# 首頁

自上而下：焦點、大時鐘、行程、隨手做。純文字清單，一眼看完。大時鐘旁常駐一句鼓勵——做完了一天是「今天的事都做完了，了不起」。

兩區交互**完全統一**（行程 / 隨手做）：
- **頭部（左側）長按 120ms = 拖拽**：拖到**底部紅色垃圾桶**（5 秒可復原），或跨模組拖（隨手做進行程區 = 選個時間轉行程、首頁行拖到頂部 = 設為焦點）。
- **尾部（右側）長按 = 進入多選**。多選態下頭部換成灰色拖柄圖示，尾部是唯一勾選圓圈（彩色=已選）。頂欄只保留**全選**（灰色 outline 次級按鈕）與**完成**（紅色實心主按鈕），刪除統一走底部紅桶。
- **行間拖拽排序**：長按出現高亮縫（含頂部置頂縫），拖到上面=置頂、下面=下移，重啟後保留順序。

# 焦點

頁面最上方的大標語區。沒有焦點時顯示「只專注一件事」，點「開始吧」：有事就從今日未完成裡挑一件，沒有就現寫一件；也可以把任意任務**頭部長按拖到頂部**設焦點。進專注統一走底欄「專注」頁。

選定後大字顯示標題，主膠囊「只做它」自動進小步驟頁把事拆小；另有完成、換一件、編輯。完成後顯示「主線完成，漂亮」，點「下一件」繼續。

# 行程

定時任務按 rank 優先（手動排序寫入）、dueTime 兜底排列，右側標註時刻；過期未完成的僅標註日期，不變紅、不責備；手機日曆當天事件以小方點並排顯示，自動去重。未來的行程到了那天自然出現。完成的行程自動從清單消失，記錄留在統計與搜尋裡。

- **行程區內行間拖拽排序**：同首頁兩區統一交互。
- **點行尾小圓鈕**可「不做了」（可復原）或「改日再做」（推到明天 / 後天 / 三天後或自選日期）。
- **長按「行程」小標題**進多選態，頂欄全選 + 完成，刪除拖紅桶。
- **新建行程**（右上角加號）：可換行一次寫多件，選一個共同的日期時間一次排進。
- **到點懸浮提醒**預設開啟；「寫入日曆」「系統鬧鐘」是可選項——編輯器裡點對應按鈕，或批量新建時點亮膠囊，才會執行。

# 隨手做

沒定時間的事都待在這。右上角加號可一次寫多件，換行或句末標點自動拆成多條。

- **隨手做區內行間拖拽排序**：同首頁兩區統一交互。
- **頭部長按跨模組拖到行程區**：先彈編輯器讓你選日期時間，**確認後**才刪原條目；中途取消則原條目不動。
- **點行尾**打開編輯器，可就地設時間變行程。

# 思維導圖

- **頁頂欄**：批量匯入（多選行程/隨手做/步驟，掛到當前導圖根節點下）+ 重排。
- **底部工具列**：根選中 = 加子節點（accent 主）+ 批量整理；非根選中 = 加子節點 + 編輯 + 批量整理；未選中時只留「批量整理」入口。**刪除統一走底部紅桶**（長按節點 120ms 起拖），工具列不再提供刪除按鈕。
- **節點**支援三種交互（完全解耦，互不干擾）：
  - **點按**：選中；**雙擊**：編輯文字。
  - **按住拖動（Listener raw pointer）**：連同子樹一起自由擺放；**雙指縮放**整張圖；重排鈕恢復自動佈局。
  - **長按 120ms 不動 → 起拖進底部紅桶**：刪除該節點（含子枝），5 秒可復原——和首頁兩區/搜尋/步驟頁的刪除邏輯**完全統一**。根節點禁拖（根不可刪）。
- **匯入節點**：把行程 / 隨手做 / 小步驟多選複製進導圖（頂欄匯入掛根節點下；也可在底部工具列選中節點後匯入掛子枝），原條目不動。

# 全局觸覺 / 視覺回饋

- **起拖**：mediumImpact 震動 + 120ms 長按觸發 + 浮影 scale 1.02 + 柔和陰影 + 圓角懸浮感。
- **懸停**（排序縫 / 紅桶 / 行程區落點）：邊沿震動（只在首次進入時震一次，懸停期間不連震）+ 高亮縫陰影。
- **長按進多選 / 切換中選**：selectionClick 震動。

# 服藥

底欄第一格。按日期翻頁查看每天該吃的藥，按時刻先後排序；藥品卡顯示名稱、劑量、服藥時刻與分類。右下角加號新建計畫：寫藥名、逐個新增服藥時刻（24 小時制，任意幾個都行），還可填劑量、分類與起止日期；儲存後按所設時刻逐日自動到點提醒並綁定系統鬧鐘（未來 30 天滾動），刪除計畫自動撤銷。右上角日曆圖示切到月曆視圖，哪天該吃、哪天已服一眼看清，點日期跳回當天。點藥品卡左側圓圈記錄當次已服，頂部分類膠囊一鍵篩選。服藥資料獨立保存，不進首頁清單與搜尋結果。

# 搜尋

首頁頂欄設定左側的放大鏡，全域搜尋標題與備註，行程、隨手做、小步驟都能命中，搜到即可直達編輯。交互同首頁兩區：**頭部長按拖紅桶刪**（5 秒復原）；**尾部長按進多選**；頂欄全選 + 完成。

# 動手吧

底欄中央紅色圓鈕。點按進入文字速記：先寫下來，不必分類；點「倒進來」後按行與句末標點（。！？；…）自動拆成多件，進入理一理。

# 理一理

底部輸入條可直接速記：換行多寫幾條，儲存時按行與句末標點自動拆成多條暫存，與「動手吧」同一規則。
分類：逐條分到行程（可設日期時間）或隨手做，分類後自動流入首頁對應區域。
思維導圖點按選中節點後可加子枝、加同級、編輯、刪除；按住拖動可連同子樹移動，雙指縮放。
右上角加號新建單條暫存；點「批量整理」進入批量操作，支援全選。

# 提醒與日曆

行程設好時間後，到點懸浮提醒預設開啟；「寫入日曆」「系統鬧鐘」為可選項，在編輯器裡點對應按鈕（或批量新建時點亮膠囊）才會執行。服藥計畫儲存後自動逐日設好提醒並綁定系統鬧鐘，刪除計畫自動撤銷。
提醒全部在本機完成，重啟或清理後台後自動重排；相關開關在設定內。

# 專注與統計

專注：僅顯示圓環與倒數數字，無干擾。時長在進入專注前選擇：預設 2 / 25 / 45 分鐘，或自訂 1–240 分鐘，當前時長會大字顯示。每分鐘滴答一聲、做完提示方式與音量在設定中調整。
統計：以日期為維度，左右滑動切換查看不同日期的專注分鐘、專注次數、完成件數、新增條目和 24 小時整點分布。純文字大數字，客觀記錄進展。

# 資料與更新

搜尋裡可以找到並刪除任何條目，誤刪可復原。設定中可匯出 JSON 備份，匯入前自動快照、可復原。解除安裝應用即刪除全部資料，請先匯出。有新版本時會自動提醒。

# 擴充功能（預覽，API 僅保留）

設定 → 擴充裡有三個自願開啟的能力：在線語音辨識（允許系統走在線引擎，辨識更准）、AI 助手（預設免費模型或自填任意 OpenAI 相容介面，僅在點「AI 整理」時發送當時那段話）、雲端備份（WebDAV，備份到你自己的伺服器或堅果雲，僅手動觸發）。不開不用就不聯網，設定只存在本機。
