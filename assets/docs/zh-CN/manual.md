启序（英文名 Start）是一款本地记事工具：把待办拆成小步骤，帮你一次只做好一件事。为神经多样性人士设计：措辞鼓励、低阻力、不责备。所有数据默认仅存于设备本地；除检查更新外，在线语音、AI 助手、云备份均为默认关闭的可选功能，开启后才会在你主动使用时联网。

> 原创与 AI 辅助声明：本应用由个人开发者独立设计，开发过程中借助人工智能工具辅助编码；产品的设计方案、交互逻辑与工作流程均为开发者原创，AI 仅用于功能实现，不参与原创设计，开发者仅对产品的"现状"负责。

> 扩展功能为预览状态，仅保留 API 接口，核心交互暂且移除，请等待后续更新。

# 首页

自上而下：焦点、大时钟、日程、随手做。纯文字清单，一眼看完。大时钟旁常驻一句鼓励——做完了一天是「今天的事都做完了，了不起」。

两区交互**完全统一**（日程 / 随手做）：
- **头部（左侧）长按 120ms = 拖拽**：拖到**底部红色垃圾桶**（5 秒可撤销），或跨模块拖（随手做进日程区 = 选个时间转日程、首页行拖到顶部 = 设为焦点）。
- **尾部（右侧）长按 = 进多选**。选择态下头部换成灰色拖柄图标，尾部是唯一勾选圆圈（彩色=已选）。顶部栏只保留**全选**（灰色 outline 次级按钮）与**完成**（红色实心主按钮），删除统一走底部红桶。
- **行间拖拽排序**：长按时隙插入高亮缝（含顶部置顶缝），拖到上面=置顶、下面=下移，重启后保留顺序。

# 焦点

页面最上方的大标语区。没有焦点时显示「只专注一件事」，点「开始吧」：有事就从今日未完成里挑一件，没有就现写一件；也可以把任意任务**头部长按拖到顶部**设焦点。进专注统一走底栏「专注」页。

选定后大字显示标题，主胶囊「只做它」自动进小步骤页把事拆小；另有完成、换一件、编辑。完成后显示「主线完成，漂亮」，点「下一件」继续。

# 日程

定时任务按 rank 优先（手动排序写入）、dueTime 兜底排列，右侧标注时刻；过期未完成的仅标注日期，不变红、不责备；手机日历当天事件以小方点并排显示，自动去重。未来的日程到了那天自然出现。完成的日程自动从清单消失，记录留在统计与搜索里。

- **日程区内行间拖拽排序**：同首页两区统一交互。
- **点行尾小圆钮**可「不做了」（可撤销）或「改日再做」（推到明天 / 后天 / 三天后或自选日期）。
- **长按「日程」小标题**进选择态，顶栏全选 + 完成，删除拖红桶。
- **新建日程**（右上角加号）：可换行一次写多件，选一个共同的日期时间一次排进。
- **到点悬浮提醒**默认开启；「写入日历」「系统闹钟」是可选项——编辑器里点对应按钮，或批量新建时点亮胶囊，才会执行。

# 随手做

没定时间的事都待在这。右上角加号可一次写多件，回车换行或句末标点自动拆成多条。

- **随手做区内行间拖拽排序**：同首页两区统一交互。
- **头部长按跨模块拖到日程区**：先弹编辑器让你选日期时间，**确认后**才删原条目；中途取消则原条目不动。
- **点行尾**打开编辑器，可就地设时间变日程。

# 思维导图

- **页顶栏**：批量导入（多选日程/随手做/步骤，挂到当前导图根节点下）+ 重排。
- **底部工具栏**：根选中 = 加子节点（accent 主）+ 批量整理；非根选中 = 加子节点 + 编辑 + 批量整理；未选中时只留「批量整理」入口。**删除统一走底部红桶**（长按节点 120ms 起拖），工具栏不再提供删除按钮。
- **节点**支持三种交互（完全解耦，互不干扰）：
  - **点按**：选中；**双击**：编辑文字。
  - **按住拖动（Listener raw pointer）**：连同子树一起自由摆放；**双指缩放**整张图；重排钮恢复自动布局。
  - **长按 120ms 不动 → 起拖进底部红桶**：删除该节点（含子枝），5 秒可撤销——和首页两区/搜索/步骤页的删除逻辑**完全统一**。根节点禁拖（根不可删）。
- **导入节点**：把日程 / 随手做 / 小步骤多选复制进导图（顶栏导入挂根节点下；也可在底部工具栏选中节点后导入挂子枝），原条目不动。

# 全局触觉 / 视觉反馈

- **起拖**：mediumImpact 震动 + 120ms 长按触发 + 浮影 scale 1.02 + 柔和阴影 + 圆角悬浮感。
- **悬停**（排序缝 / 红桶 / 日程区落点）：边沿震动（只在首次进入时震一次，悬停期间不连震）+ 高亮缝阴影。
- **长按进多选 / 切选中**：selectionClick 震动。

# 服药

底栏第一格。按日期翻页查看每天该吃的药，按时刻先后排序；药品卡显示名称、剂量、服药时刻与分类。右下角加号新建计划：写药名、逐个添加服药时刻（24 小时制，任意几个都行），还可填剂量、分类与起止日期；保存后按所设时刻逐日自动到点提醒并绑定系统闹钟（未来 30 天滚动），删除计划自动撤销。右上角日历图标切到月历视图，哪天该吃、哪天已服一眼看清，点日期跳回当天。点药品卡左侧圆圈记录当次已服，顶部分类胶囊一键筛选。服药数据独立保存，不进首页清单与搜索结果。

# 搜索

首页顶栏设置左边的放大镜，全局搜索标题与备注，日程、随手做、小步骤都能命中，搜到即可直达编辑。交互同首页两区：**头部长按拖红桶删**（5 秒撤销）；**尾部长按进多选**；顶栏全选 + 完成。

# 动手吧

底栏中央红色圆钮。点按进入文字速记：先写下来，不必分类；点「倒进来」后按行与句末标点（。！？；…）自动拆成多件，进入捋一捋。

# 捋一捋

底部输入条可直接速记：回车换行多写几条，保存时按行与句末标点自动拆成多条暂存，与「动手吧」同一规则。
分类：逐条分到日程（可设日期时间）或随手做，分类后自动流入首页对应区域。
思维导图点按选中节点后可加子枝、加同级、编辑、删除；按住拖动可连同子树移动，双指缩放。
右上角加号新建单条暂存；点「批量整理」进入批量操作，支持全选。

# 提醒与日历

日程设好时间后，到点悬浮提醒默认开启；「写入日历」「系统闹钟」为可选项，在编辑器里点对应按钮（或批量新建时点亮胶囊）才会执行。服药计划保存后自动逐日设好提醒并绑定系统闹钟，删除计划自动撤销。
提醒全部在本机完成，重启或清理后台后自动重排；相关开关在设置内。

# 专注与统计

专注：仅显示圆环与倒计时数字，无干扰。时长在进入专注前选择：预设 2 / 25 / 45 分钟，或自定义 1–240 分钟，当前时长会大字显示。每分钟滴答一声、做完提示方式与音量在设置中调整。
统计：以日期为维度，左右滑动切换查看不同日期的专注分钟、专注次数、完成件数、新增条目和 24 小时整点分布。纯文字大数字，客观记录进展。

# 数据与更新

搜索里可以找到并删除任何条目，误删可撤销。设置中可导出 JSON 备份，导入前自动快照、可撤销。卸载应用即删除全部数据，请先导出。有新版本时会自动提醒。

# 扩展功能（预览，仅保留 API 接口）

设置 → 扩展里有三个自愿开启的能力：在线语音识别（允许系统走在线引擎，识别更准）、AI 助手（预设免费模型或自填任意 OpenAI 兼容接口，仅在点「AI 整理」时发送当时那段话）、云备份（WebDAV，备份到你自己的服务器或坚果云，仅手动触发）。不开不用就不联网，配置只存在本机。

> 以上扩展功能为预览状态，仅保留 API 接口，核心交互暂且移除，请等待后续更新。
