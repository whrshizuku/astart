工作流

丢 → 捋 → 做，三步把杂乱变成行动

丢进来

点底栏中央红色键「动手吧」，一股脑全写下来，不用想分类，写完「倒进来」

→

捋一捋

把每条暂存分到日程或随手做；嫌哪条大就在思维导图或拆词里拆开

→

开始做

把日程拖到顶部「焦点」区，一天只盯它；嫌它大就拆成小步骤，一步一步来

所有删除都有 5 秒撤销，删错了随时拉回来

记录

动手吧

底栏中央红钮。短按文字速记，自动按行和句末标点拆成几件倒进捋一捋；长按语音速记——内置开源 Vosk 引擎，自带中文模型，实时转写、自动续听。

随手做加号

想到什么丢什么。回车换行多记几条、按行自动拆开，直接进随手做。

捋一捋

分拣中枢，也能直接速记。逐条分类为日程或随手做，加号支持一次写多条，批量操作与全选。

整理

拆词

按词单元拆分，词、句、混写自动分辨；词芯片默认全选、单击取消、双击删词、长按拖动换位。

思维导图

捋一捋内置，自由编辑删除——加子枝 / 加同级 / 编辑 / 删除，按住拖动节点连同子树自由摆放，双指缩放。

拆成小步骤

焦点专属。标题只是事件名，永远不会被拆；输入条写一步存一步，按行自动拆条，步骤可编辑、拖动排序，全完成自动勾掉任务。

执行

服药

按日期翻页管理每日用药；服药时刻完全自定义（24 小时制任意时间点），保存后逐日自动设到点提醒并绑定系统闹钟；右上角日历图标切月历视图，可查看每日用药状态；点圆圈记录已服。

日程

定时任务按时刻排成纯文字清单，右侧标时刻；过期仅标日期，不改红不责备。点时刻胶囊闪红改时间；行尾小圆钮展开「不做了 / 改日再做」；长按小节标题批量删除。提醒 / 写入日历 / 系统闹钟三项可选。

焦点

页面最上方大标语区——「今天只做一件就好」，点「选一件」挑一件。一屏一事，主胶囊「只做它」直接进专注，完成就地鼓励。

专注

只显示空心圆环和倒计时数字，时长自定义。滴答声可选，结束有提示音。

随手做

没时间的事都待在这；加号可一次写多件，回车换行或句末标点自动拆成多条直接存入；拖行尾手柄排序；拖进日程区选个时间就转成日程。

统计

按日期查看，从首次使用到今天一天一页，左右滑动切换；当日专注分钟、专注次数、完成的事、新增条目四个大数字，配整点专注分布柱状图。

安心

全局撤回

任何删除（含思维导图节点）都有 5 秒撤销栏，防误删。

到点悬浮提醒

日程到时间弹横幅通知，支持系统闹钟，重启后自动恢复。后台常驻通知降低被系统终止的可能 + 开机自启动重排提醒。

搜索与导入导出

首页顶栏放大镜就是全部任务管理台——分类胶囊筛选、批量删除、搜到即可编辑。系统文件选择器存取数据文件，导入前自动快照可撤销。

界面

纯图标

无文字按钮，全局统一墨色与番茄红点缀，数字等宽严格对齐。

深色模式

跟随系统 / 开 / 关三态；字号小中大可选。

多语言

跟随系统 / 简体中文 / 繁體中文 / English / 日本语，设置里可手动切换。简体中文显示「启序」，其他语种显示「Start」。

全面屏

内容延伸状态栏与手势条，透明系统栏自适应明暗。

隐私

无账户、无广告、无统计 SDK
