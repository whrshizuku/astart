# 启序 · Start

**中文名「启序」，英文名「Start」**——一款为神经多样性人士设计的本地待办工具：把心里的事一股脑写下来，捋成日程与随手做，再把待办拆成小步骤，一次只做好一件事。

措辞鼓励、低阻力、不责备：过期的日程不变红、不催促，做完的事有掌声。数据全部只存在你手机里（start_items.json），卸载即清空；除检查更新外默认不联网，设置里的扩展功能（AI 助手、在线语音识别、云备份）均为预览状态，仅保留接口。

## 工作流

```
丢 → 捋 → 做
```

1. **丢**：点底栏中央的红色圆钮「动手吧」，想到什么一股脑全写下来，不用想分类；回车换行与句末标点自动拆成几件，点「倒进来」存进捋一捋。
2. **捋**：去「捋一捋」，把每条暂存分到日程（选个日期时间）或随手做；嫌哪条大，就用「大爆炸」拆词拆小，或开成思维导图慢慢拆。
3. **做**：回首页，把日程长按拖到顶部设为今日焦点，一天只盯它；嫌它大就拆成小步骤，一步一步来。

所有删除统一 **5 秒撤销**，删错了随手拉回来，不用紧张。

## 功能

### 首页

- 顶栏是 Start 字标、搜索与设置；页面自上而下：今日焦点、大时钟与日期、日程、随手做，纯文字清单，一眼看完一天。
- 大时钟旁常驻一句鼓励语——「还有 N 件，一件件来」；一天的事都做完了，就是「今天的事都做完了，了不起」。

### 今日焦点

- 没有焦点时，点「开始吧」：现写一件，或从今天未完成的事里选一件；也可以把任意日程长按拖到顶部，直接设为焦点。
- 选定后大字显示标题，主胶囊「只做它」带你进小步骤页，把事拆小再动手，降低启动阻力。
- 完成后显示「主线完成，漂亮」，点「下一件」继续，节奏不断。

### 小步骤

- 标题只是事件名，永远不会被拆；输入条写一步存一步，回车换行一次多写几步，保存时按行自动拆开。
- 全部步骤完成时，任务自动勾掉，不用回头收拾。

### 日程

- 定时任务按时刻排成纯文字清单，右侧标注时刻；过期未完成的仅安静标出日期，不变红、不责备。
- 手机日历里的当天事件以小方点并排显示，与写入日历的任务自动去重。
- 未来的日程不到今天不出现，到了那天自然来到清单里；完成的日程自动从清单消失，记录留在统计与搜索里。
- **新建日程**：右上角加号打开，可多行一次写好几件，选一个共同的日期时间批量排进；到点悬浮提醒默认开启。
- **「写入日历」「系统闹钟」为可选项**：编辑器里点对应按钮，或批量新建时点亮对应胶囊才会执行，保存日程不替你自动做。
- **行尾小圆钮**展开「不做了 / 改日再做」：不做了整件移除（可撤销）；改日再做可推到明天、后天、三天后或自选日期，提醒自动跟随。
- **批量删除**：长按「日程」小标题进入选择态，逐条勾选或全选，点顶栏垃圾桶整批删除，同样可撤销。

### 随手做

- 没定时间的事都待在这；右上角加号一次写多件，回车换行或句末标点自动拆成多条直接存入。
- 拖行尾手柄上下排序；点行进编辑器，就地设个时间便转成日程。

### 全局拖拽

- 任意条目长按拖起，底部升起红区垃圾桶，扔进去即删，5 秒内可撤销。
- 多选状态下拖任一已选条目，整组一起删除。
- 把日程拖到顶部即设为焦点；把随手做拖进日程区，选个时间就转成日程。

### 服药

- 底栏第一格。按日期翻页查看每天该吃的药，按时刻先后排序；药品卡显示名称、剂量、服药时刻与分类。
- **新建计划**：写药名，逐个添加服药时刻（24 小时制，任意几个都行），还可填剂量、分类与起止日期。
- **自动提醒**：保存后按所设时刻逐日自动到点提醒并绑定系统闹钟（未来 30 天滚动）；按日期范围的计划不绑系统闹钟。删除计划时，提醒与系统闹钟一并自动撤销。
- **月历视图**：右上角日历图标切换，哪天该吃、哪天已服一眼看清；点药品卡左侧圆圈记录当次已服；顶部分类胶囊一键筛选。
- 服药数据独立保存，不进首页清单与搜索结果；保存与编辑计划时按需申请通知与日历权限，缺哪个问哪个。

### 专注

- 番茄钟专注页：只显示空心圆环与倒计时数字，没有多余干扰。
- 开始前选时长：预设 2 / 25 / 45 分钟，或自定义 1–240 分钟，当前时长大字可见。
- 进行中可暂停、提前完成或不做了；做满一分钟以上，中途停下也会记下已专注的分钟，不白做。
- 每分钟滴答一声、做完的提示方式（声音 / 震动 / 静默）与音量，都在设置里调。

### 统计

- 按日期查看：从首次使用到今天一天一页，左右滑动切换。
- 每页四个大数字：当日专注分钟、专注次数、完成的事、新增条目；底部是当日整点专注分布柱状图。看得见自己的进展，不制造焦虑。

### 搜索

- 首页顶栏的放大镜，全局搜索标题与备注，日程、随手做、小步骤都能命中，搜到即可直达编辑。

### 设置

- **界面语言**：简体中文 / 繁體中文 / English / 日本语，默认跟随系统，手动切换即时生效；简体中文下应用名显示「启序」，其他语种显示「Start」。
- **外观**：深色模式（跟随系统 / 开 / 关）与字号；**触感与音效**：按压触感、专注滴答声、完成提示方式与音量。
- **提醒**：到点悬浮提醒开关、常驻悬浮窗开关。
- **数据**：导出 / 导入 JSON 备份，导入前自动快照、可撤销；恢复出厂需二次确认，清空全部数据。
- **扩展**：AI 助手、在线语音识别、云备份（WebDAV）均为预览状态，仅保留接口，默认关闭，请等待后续更新。
- **关于**：查看说明书、用户协议、隐私政策、开源许可，检查更新与联系作者。

### 安心

- **提醒可靠**：到点提醒走闹钟级渠道（铃声、震动、全屏亮屏）；每次冷启动自动重挂全部日程与服药提醒，重启手机后自动重排，清理后台也不丢。
- **撤销统一 5 秒**：任何删除都有 5 秒撤销窗口，删错了随手拉回来。
- **数据在本地**：全部数据只存在手机里的 start_items.json，无账户、无广告、无统计 SDK，卸载即清空。

### 界面

- 纯文字、无花哨装饰，墨色配番茄红点缀，数字等宽严格对齐。
- 深色模式跟随系统或手动开关；字号小中大可调；全面屏自适应明暗。

## 隐私

| 权限 | 用途 |
|------|------|
| READ_CALENDAR | 首页日程区并排显示手机日历当天事件（只读） |
| WRITE_CALENDAR | 点「写入日历」时把日程存进手机日历 |
| SET_ALARM | 服药计划与日程按需绑定系统闹钟 |
| SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM / POST_NOTIFICATIONS | 日程与服药的到点提醒、常驻悬浮窗 |
| USE_FULL_SCREEN_INTENT / VIBRATE / WAKE_LOCK | 提醒走闹钟级渠道：铃声、震动、全屏亮屏 |
| RECEIVE_BOOT_COMPLETED | 重启手机后自动重排提醒 |
| INTERNET | 检查更新；扩展功能（AI 助手 / 在线语音识别 / 云备份）为预览状态，仅保留接口 |
| RECORD_AUDIO | 语音识别接口预留（扩展预览，当前版本未启用） |

无账户、无广告、无统计 SDK，数据默认仅存设备本地。详见应用内「隐私政策」。
