# Start

**把待办和念头拆成小步骤、一次只做好一件事**的本地记事工具。

为 ADHD 人群设计：措辞鼓励、低阻力、不责备。数据只存在你手机里，唯一的联网行为是检查更新。

## 工作流

```
丢 → 捋 → 做
```

1. **丢**：点底栏中央红色键「动手吧」，一股脑全写下来，不用想分类，写完「倒进来」。
2. **捋**：去「捋一捋」，把每条暂存分到念头 / 日程 / 随手做；嫌哪条大就在思维导图或拆词里拆开。
3. **做**：回首页，把日程**拖到「今日焦点」格子上**，一天只盯它；嫌它大就「拆成小步骤」，一步一步来。

所有删除都有 **6 秒撤销**，删错了随时拉回来。

## 功能

### 记录

- **念头**：想到什么丢什么。底部输入条直接写，**回车换行多记几条、按行自动拆开**；写完点拆词图标可捋一捋。
- **动手吧**：底栏中央功能键速记。自动按行和句末标点（。！？；…）拆成几件，倒进捋一捋。
- **捋一捋**：分拣中枢，也能直接速记（底部输入条写下来自动拆成多条暂存，点拆词按钮先拆词再存）。逐条分类为念头 / 日程（设日期时间）/ 随手做，加号支持一次写多条，批量操作与全选。

### 整理

- **拆词**：ICU 词典**按词单元**拆分，词、句、混写自动分辨；词芯片默认全选、单击取消、双击删词、长按拖动换位。
- **思维导图**：捋一捋内置，自由编辑删除——加子枝 / 加同级 / 编辑 / 删除，按住拖动节点连同子树自由摆放，双指缩放。
- **拆成小步骤**：今日焦点专属。标题只是事件名，**永远不会被拆**；输入条写一步存一步，回车换行多写几步、按行自动拆条，写的内容也能拆词；步骤可编辑、拖动排序，全完成自动勾掉任务。

### 执行

- **首页**：从上到下——大时钟、日程时间轴、随手做、今日焦点，今天的全貌一眼看清。
- **日程时间轴**：定时的任务挂在时间轴上，红色「现在」线标出当下；完成的实心点、未到的空心圈、过期的灰圈——过期不改红、不责备；手机日历当天事件以小方点并排显示，写进日历的任务自动去重。
- **日程编辑三开关**：**提醒**（到点悬浮通知，设了时间默认打开）、**写入日历**（存进手机日历，写过的标「已在日历」可直达）、**系统闹钟**（跳系统时钟，用厂商闹钟响）。日程右上角加号新建日程，打开即选日期时间，三项设置排在日期下方；没写内容或没选时间不会保存，不留空白日程、不流落随手做。
- **随手做**：没时间的事都待在这；右上角加号可一次写多件，回车换行或句末标点自动拆成多条直接存入。
- **今日焦点**：首页最底部的浅红格子，把日程**拖上来**就是今天的焦点。一屏一事，大按钮直接进专注，完成就地有鼓励。
- **专注**：只显示空心圆环和倒计时数字，时长自定义。
- **统计**：完成数与专注分钟，看得见自己的进展。

### 安心

- **全局撤回**：任何删除（含思维导图节点）都有 6 秒撤销栏，防误删。
- **到点悬浮提醒**：日程到时间弹横幅，系统精准闹钟，重启不丢。
- **后台保活**：常驻通知防误杀 + 开机自启动重排提醒，设置里可开关。
- **数据导入导出**：系统文件选择器存取 JSON，导入前自动快照可撤销。
- **检查更新**：启动静默查 Gitee Releases，发现新版自动提醒；设置里「检查更新」右侧即当前版本号，随包自动变化。

### 界面

- **纯图标**：无文字按钮，全局统一墨色与番茄红点缀，数字等宽严格对齐。
- **深色模式**：跟随系统 / 开 / 关三态；字号小中大。
- **全面屏**：内容延伸状态栏与手势条，透明系统栏自适应明暗。

## 隐私

| 权限 | 用途 |
|------|------|
| READ_CALENDAR | 首页时间轴并排显示手机日历当天事件（只读） |
| WRITE_CALENDAR | 日程开启「写入日历」时把任务存进手机日历 |
| SCHEDULE_EXACT_ALARM / POST_NOTIFICATIONS | 日程到点提醒与保活通知 |
| RECEIVE_BOOT_COMPLETED | 开机后重排提醒 |
| INTERNET | 仅检查更新 |

无账户、无广告、无统计 SDK，数据仅存设备本地。详见应用内「隐私政策」。
