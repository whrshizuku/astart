# 启序 · Start

**中文名「启序」，英文名「Start」**——一款为神经多样性人士设计的本地待办工具：把心里的事一股脑写下来，捋成日程与随手做，再把待办拆成小步骤，一次只做好一件事。

措辞鼓励、低阻力、不责备：过期的日程不变红、不催促，做完的事有掌声。数据全部只存在你手机里（start_items.json），卸载即清空；除检查更新外默认不联网，设置里的扩展功能（AI 助手、在线语音识别、云备份）均为预览状态，仅保留接口。

## 三心法：丢 → 捋 → 做

1. **丢**：点底栏中央的红色圆钮「动手吧」，想到什么一股脑全写下来，不用想分类；回车换行与句末标点自动拆成几件，点「倒进来」存进捋一捋。
2. **捋**：去「捋一捋」，把每条暂存分到日程（选个日期时间）或随手做；嫌哪条大，就用「大爆炸」拆词拆小，或开成思维导图慢慢拆。
3. **做**：回首页，头部长按把日程拖到顶部设为今日焦点，一天只盯它；嫌它大就拆成小步骤，一步一步来。

所有删除统一 **5 秒撤销**，删错了随手拉回来，不用紧张。

---

## 全局交互：一套手势走遍全应用

日程、随手做、搜索、步骤、思维导图**全部统一**：

| 手势 | 行为 |
|------|------|
| 头部长按 120ms | 起拖 → 底部红桶删除 / 跨模块移动 / 行间排序 |
| 尾部长按 | 进多选 |
| 点按 | 进编辑器（多选态下为切换选中） |
| 删除 | 统一拖到底部红色垃圾桶，5 秒撤销 |

**选择态**：头部灰色拖柄、尾部勾选圆圈；顶栏只有全选（灰色 outline）+ 完成（红色实心）+ 退出。工具栏不再提供删除按钮。

**反馈**：起拖 `mediumImpact`、悬停 `lightImpact`（边沿触发只震一次）、进多选 `selectionClick`；拖拽浮影微放大 + 柔和阴影。

## 功能速览

### 首页

- 顶栏是 Start 字标、搜索与设置；页面自上而下：今日焦点、大时钟与日期、日程、随手做，纯文字清单，一眼看完一天。
- 大时钟旁常驻一句鼓励语——「还有 N 件，一件件来」；一天的事都做完了，就是「今天的事都做完了，了不起」。

### 今日焦点

- 没有焦点时，点「开始吧」：现写一件，或从今天未完成的事里选一件；也可以把任意日程**头部长按拖到顶部**，直接设为焦点。
- 选定后大字显示标题，主胶囊「只做它」带你进小步骤页，把事拆小再动手，降低启动阻力。
- 完成后显示「主线完成，漂亮」，点「下一件」继续，节奏不断。

### 日程

- 定时任务按手动 rank（拖拽写入）优先、dueTime 兜底排列；右侧标注时刻。
- 手机日历当天事件以小方点并排显示，自动去重（只读，不参与排序）。
- 未来的日程不到今天不出现；完成的日程自动从清单消失，记录留在统计与搜索里。
- **新建日程**：右上角加号打开，可多行一次写好几件，选一个共同的日期时间批量排进；到点悬浮提醒默认开启。
- **「写入日历」「系统闹钟」为可选项**：编辑器里点对应按钮，或批量新建时点亮对应胶囊才会执行。
- **行尾小圆钮**展开「不做了 / 改日再做」：不做了整件移除（可撤销）；改日再做可推到明天、后天、三天后或自选日期。

### 随手做

- 没定时间的事都待在这；右上角加号一次写多件，回车换行或句末标点自动拆成多条直接存入。
- **行间拖拽排序**：拖到目标行上方的高亮缝里松手，rank 立即写入，重启保留。
- **拖进日程区**：先弹编辑器让你选时间，**确认后**才删原条目；中途取消原条目不动。

### 思维导图

- **顶栏**：批量导入（多选日程/随手做/步骤，挂当前导图根节点下）+ 重排。
- **底部工具栏**：根选中 = 加子节点（主）+ 批量整理；非根选中 = 加子 + 编辑 + 批量；未选中 = 批量入口。
- **节点三交互，完全解耦零冲突**：
  - **点按**选中；**双击**编辑文字。
  - **按住拖动**自由摆放（Listener raw pointer，连同子树）；双指缩放；重排恢复自动布局。
  - **长按 120ms 不动 → 拖进底部红桶删**（含子枝，根禁拖）——与其他页面删除逻辑完全统一。

### 服药

- 底栏第一格。按日期翻页查看每天该吃的药，按时刻先后排序。
- **新建计划**：写药名，逐个添加服药时刻（24 小时制），可填剂量、分类与起止日期。
- **自动提醒**：保存后按所设时刻逐日自动到点提醒并绑定系统闹钟（未来 30 天滚动）。
- **月历视图**：右上角日历图标切换，状态点三色一眼看清——绿=全部已服、黄=部分已服、番茄红=漏服（灰=未来）；点日期跳回当天；顶部分类胶囊一键筛选。

### 专注 & 统计

- **专注**：只显示空心圆环与倒计时数字，预设 2/25/45 分钟或自定义 1-240 分钟；每分钟滴答、完成提示在设置里调。
- **统计**：按日期左右滑，每页四个大数字（当日专注分钟、专注次数、完成件数、新增条目）+ 24 小时整点分布柱状图。

### 搜索

- 顶栏放大镜，全局搜日程/随手做/步骤。交互同首页两区：头部长按拖红桶删；尾部长按进多选；批量态工具栏带全选 + 完成 + 退出。

### 设置

- **界面语言**：简中 / 繁中 / English / 日本语，跟随系统或手动切。
- **外观**：深色模式（跟随 / 开 / 关）与字号。
- **触感与音效**：按压触感、专注滴答声、完成提示方式与音量。
- **提醒**：到点悬浮提醒、常驻悬浮窗开关。
- **数据**：导出 / 导入 JSON，导入前自动快照、可撤销。
- **扩展**：AI 助手、在线语音识别、云备份（WebDAV）均为预览状态，默认关闭。

## 安全可靠

- **提醒**：到点提醒走闹钟级渠道；冷启动自动重挂全部提醒；重启手机、清理后台后自动重排。
- **数据**：所有数据本地存储（JSON）；设置里可导出 / 导入；卸载即清空。
- **无追踪**：不埋点、不追踪、不收集；除检查更新外不联网。
